# Daily Journal Blog

This is the publish-only companion to `~/daily driver`. Journal entries are
written through `today notes` and exported here only when **Publish to blog** or
`today publish` is used.

The site is built with Jekyll and deployed to GitHub Pages by
`.github/workflows/pages.yml`. Calibration and validation directories are never
read, committed, or published.

## Publishing

Once this repository has a GitHub `origin` and SSH authentication:

```sh
today notes      # edit locally and use Publish to blog
today publish    # publish the saved journal from the terminal
```
